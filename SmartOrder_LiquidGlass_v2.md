# Smart Order — Liquid Glass v2

[Скачать полный архив исходников](https://github.com/yaebalprincess/yaebal/raw/refs/heads/smartorder-liquid-glass-v2/SmartOrder_LiquidGlass_v2_source.zip)

Обновление первого окна «Наряд» по согласованному стеклянному макету:

- Окно занимает всю клиентскую область, фон не выходит за рамки.
- Градиент наведения следует за курсором; возвращены анимации нажатия.
- По Esc появляется исходная анимированная подсказка с белым фоном.
- Четыре фильтра стоят в одном ряду, при необходимости доступна прокрутка.
- Индикатор БД на странице нарядов убран; отступы исправлены для Chromium 83.
- Списки, выбор цеха и календарь используют полупрозрачные панели с размытием.

Распакуйте ZIP и запустите `PREVIEW_LIQUID_GLASS.cmd`. Нужен Python 3.12 x64.
Предпросмотр открывает отдельную временную базу. Для рабочей базы используется
штатный `main.py` с прежними настройками общей папки.

31 проверка прошла: 24 проверки окна/Qt-моста и 7 исходных проверок RC14.
Инструкция Windows-сборки и подробный отчёт включены в архив.
Готовый EXE не входит. Базы данных и личные данные в архив не включены.

# Проверка Liquid Glass v7

Дата: 6 ноября 2026 года. Среда: Python 3.12, PyQt5 / Qt WebEngine,
Linux, offscreen software rendering. Использованы временные базы и настоящий
интерфейс приложения с Chromium. Рабочие данные пользователя не изменялись.

## Результат

- Расширенный совместный прогон: **63 passed** — база, расчёты аналитики,
  интерфейс нарядов, проверки v6, новые права и персонализация v7.
- После последней оптимизации темы и подтверждения начальной отрисовки:
  **27 passed** в `tests/test_accounts_v7.py` и `tests/test_liquid_glass_v7.py`.
- Отдельный замер темы при загруженных вкладках: **0,046 / 0,048 секунды**.
  Проверено нажатие по обоим краям тумблера и отсутствие замены глобального
  QApplication stylesheet. Время относится к этой среде, не к компьютеру пользователя.
- `compileall` для Python и `node --check` для изменённых JavaScript прошли.
- Руководство v7 сгенерировано из `smartorder/user_guide.py`: HTML и PDF на 10 страниц.

## Что проверяется

- Миграция «Аналитика» в «Экономиста» с сохранением учётной записи; уведомления
  экономиста, блокировка верхней панели нарядов и доступность просмотра таблицы.
- Права конкретного пользователя вместо прав ролей, немедленная проверка доступа
  перед записью, отзыв разрешений в открытой сессии, очистка скрытых данных и выбор
  доступной вкладки. Менеджер пользователей без права выдачи разрешений не может
  изменять более привилегированную учётную запись. Проверена защита последнего администратора.
- Отложенная активация, вход до и после срока, отмена расписания ручным включением
  или отключением. Изменение роли и выдача прав проверяются в одной транзакции.
- Позиция меню цеха под кнопкой пользователя, рамки списков, отсутствие лишнего
  HTML-контура фокуса, состояния недоступных кнопок и курсор запрета.
- Отсутствие обрезки названий вкладок при 111% и смене языков. Текущий словарь
  интерфейса заполнен для казахского, французского, немецкого, японского и татарского.
  Имена и исходные значения смен остаются неизменными.
- Нижнее выравнивание кнопок редактора наряда; восстановление размера после
  перехода в полноэкранный режим и обратно.
- Первое состояние HTML-страницы после подключения Qt WebChannel получает права,
  пустое состояние и плашку без принудительной повторной отправки из теста.
  Добавлено подтверждение применения данных страницей с ограниченным повтором.
- Экспорт одного датированного JSON, импорт и загрузка профиля той же учётной записи
  на втором экземпляре программы. Фоновая отправка объединяет частые изменения
  и не блокирует тему. Локальная отметка сохраняет неотправленные настройки при перезапуске.
- Перенос фона ограничен управляемой папкой изображений; конфиг не может прочитать
  произвольный локальный файл. Импорт сохраняет собственный выбор синхронизации получателя.

## Воспроизведение

```bash
QT_QPA_PLATFORM=offscreen QT_OPENGL=software QT_QUICK_BACKEND=software \
QTWEBENGINE_DISABLE_SANDBOX=1 \
QTWEBENGINE_CHROMIUM_FLAGS='--no-sandbox --disable-gpu --disable-gpu-compositing --disable-dev-shm-usage --no-zygote' \
python -m pytest -q tests/test_accounts_v7.py tests/test_liquid_glass_v7.py
```

Для новых прав и синхронизации требуется v7 на всех клиентах общей базы.
Старые версии не учитывают индивидуальные разрешения.

## Пределы проверки

Нативная отрисовка Windows, работа с реальным сетевым диском и готовый EXE здесь
не проверялись. Причины повторной стилизации и появления вспомогательных белых окон
исправлены, но отсутствие мерцания на целевом Windows-ПК этим прогоном не подтверждается.
Qt WebEngine offscreen иногда возвращает старый кадр при `QWidget.grab()`, хотя DOM
уже обновлён. Поэтому состояние страницы проверялось через настоящий Chromium/DOM;
подтверждение страницы означает применение данных, а не проверку кадра Windows/GPU.

Глубокие справочные и методические тексты старых модулей могут оставаться на русском.
Оригинальные фото цехов и GIF в доступных файлах отсутствуют; сохраните `resources`
своей установки. В архив включены новые снимки нативной персонализации и окна пользователя.

Исторический набор целиком не объявляется проходящим: ранее выявленные ошибки
старых спецификаций описаны в [отчёте v6](LIQUID_GLASS_V6_QA.md). В v7 проверены
указанные выше целевые и регрессионные сценарии.

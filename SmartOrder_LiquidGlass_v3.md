# Smart Order · Liquid Glass v3

Стеклянное оформление внедрено во все вкладки и прикладные окна: редактор и просмотр нарядов, вход, пользователи и роли, списки выбора, календари, архивы, история, помощь, новости, уведомления, диагностика и аналитические окна.

[Скачать полные исходники ZIP](https://raw.githubusercontent.com/yaebalprincess/yaebal/smartorder-liquid-glass-v3/SmartOrder_LiquidGlass_v3_source.zip)

Рабочий запуск после распаковки: `START_SMARTORDER.cmd`. Требуется Python 3.12 x64. Для изолированного предпросмотра: `PREVIEW_LIQUID_GLASS.cmd`.

Бизнес-модули, SQLite, расчёты, права, версии, блокировки и Excel сохранены. 107 проверок выбранного набора прошли, включая изменение через HTML и сохранение новой версии наряда. Внутри архива — документация, результаты проверки и изображения интерфейса.

В комплекте исходники; Windows EXE не включён и Windows-сборка здесь не проверялась. Системные окна выбора файлов Windows сохранены.

Размер: 3781209 байт. Файлов в архиве: 105.

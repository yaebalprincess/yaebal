# Проверка Liquid Glass v6

Среда: Python 3.12, PyQt5 / Qt WebEngine, Linux, offscreen software rendering.
Проверки используют временные базы и настоящее главное окно с Chromium.

## Проверено

- Финальный совместный прогон: **16 passed** — все 13 случаев
  tests/test_liquid_glass_v6.py, шрифты и геометрия панели из v4,
  маршрутизация после смены цеха из RC19.
- Проверяются направления переключателя темы, три языка, неизменность значений
  смен, применение сохранённого профиля при запуске.
- Проверяются отсутствие новых видимых верхнеуровневых окон при первом обходе
  вкладок, совпадение экранных координат кнопок сотрудников и номенклатуры,
  центрирование подсказок пустых таблиц и нижнее положение текущей сессии.
- Проверяются изменение и сохранение ширины столбцов, отклонение неверных размеров,
  отсутствие смены глобального QApplication stylesheet при изменении масштаба,
  масштаб аналитики 100% и отсутствие перестройки во время движения ползунка.
- Проверяется реальный размер шрифта кнопки после увеличения до 140%.
  Размеры Qt QSS округляются до целых пикселей, чтобы дробное значение не
  отклонялось движком стилей с сохранением прежнего размера.
- Проверяются единственный заголовок пользователя, видимые флажки ролей,
  минимальная длина пароля, сохранение окна и веб-виджета при переключении цеха.
- Пять случаев проверяют сопоставление цеха с его именем файла и чтение фонового
  изображения. Для тестов создаются временные изображения; это не фотографии пользователя.
- Прошли проверки реального создания и сохранения наряда, истории, фильтров,
  Excel, логики базы и расчётов аналитики в целевом регрессионном прогоне.
- Расширенный набор интерфейса, базы и аналитики содержит 75 проверок: 74 прошли
  совместно, проверка геометрии панели прошла адресно после учёта скрытого в
  аналитике ползунка. Отдельно прошла маршрутизация открытия наряда после смены цеха.
- node --check для изменённых JavaScript и compileall для Python завершены успешно.

## Общий исторический набор

Дополнительный запуск всего набора содержит ошибки старых спецификаций.
В неизменённой v5 повторены 26 не прошедших исторических проверок: 25 ошибок
воспроизводятся и там. Они относятся к старым условиям исходного кода, прежнему
виду вкладок и меню, группировке Excel и локальному каналу второго процесса.
Общий исторический набор не объявляется полностью проходящим.

Ещё одна проверка требовала пересоздания окна цеха. Она обновлена под новый
асинхронный переход с сохранением окна и сессии и проходит на v6.

## Ограничения проверки

Нативный рендеринг Windows, реальные сетевые задержки и готовый EXE в этой среде
не проверялись. Изменения устраняют обнаруженные причины вспомогательных белых
окон и лишних перестроений; окончательная визуальная проверка на Windows нужна.
Не приводятся обещания времени переключения на компьютере пользователя.

Оригинальные фото цехов отсутствуют в доступном дереве репозитория и в архив
не включены. Поиск файлов реализован для папки resources установки и общей
сетевой папки; см. docs/WORKSHOP_BACKGROUNDS_RU.txt.

Архив исходников сохраняет существующие двоичные документы v5 из базового коммита.
Руководство v6 сгенерировано из smartorder/user_guide.py.

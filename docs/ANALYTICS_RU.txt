SMART ORDER · АНАЛИТИКА · ВЕРСИЯ 1.0

Аналитика доступна Администратору, Бухгалтеру и Экономисту после вкладки
«Администрирование». Все расчёты и чтение выполняются в фоне. Новые данные
пересчитывают открытый отчёт; смена вкладки не меняет общий стиль приложения.
Крупные таблицы отображают видимые ячейки, без тысяч скрытых виджетов.

Фильтры: Цех, общий выбор периода как во вкладке «Наряд», Подразделение,
Работа/код, Мастер, Смена. Внутри последних четырёх выпадающих списков есть
строка поиска. Значение «Все» снимает соответствующий фильтр. Быстрые фильтры
периода: этот месяц, этот год, прошлый год.
Строка «За сегодня» показывает сегодняшние наряды и уникальных сотрудников
из последних версий. Цех и производственные фильтры действуют на неё тоже.
Основной отчёт зависит от выбранного периода. При выборе старого года
сегодняшний счётчик продолжает показывать текущий день.

ПЯТЬ ПОКАЗАТЕЛЕЙ
Наряды — количество последних сохранённых версий разных нарядов.
Часы работы — сумма введённых часов в строках нарядов.
ФИКС Итоговый вес, кг — сумма количества коробок × веса коробки.
ФАКТ часы — значения ФАКТ только для работ с единицей «часы».
ФАКТ Оплата — рассчитанная оплата ФИКС + рассчитанная оплата ФАКТ.
Исходные компоненты сохраняются в базе; отдельной видимой ФИКС Оплаты нет.
Кольцевой график «Доли по цехам» показывает доли выбранного показателя.
При одном выбранном цехе это 100% его значения; при выборе всех — сравнение
цехов. Наведение и выбор угла 3D-профиля показывают выбранный показатель.

ДЛЯ ЧЕГО «ЕДИНИЦЫ ФАКТ»
В старой базе поле называлось «часы/кг/шт.», но единица отдельно не хранилась.
Без настройки 10 кг нельзя прибавлять к 5 часам как 15 часов.
В окне укажите для работ настоящую единицу: часы, килограммы или штуки.
В «ФАКТ часы» попадут только часы. Неуказанные единицы, кг и шт исключаются
из часов. Суммы, объём ФАКТ и оплата при этой настройке не изменяются.
Настройка относится к историческим значениям того же вида работы в цехе.
Работы из отчёта за охватываемые годы можно настроить; изменения сохраняет
пользователь с правами изменения номенклатуры. Не выбирайте «все — часы»,
если среди работ есть измеряемые в кг или штуках.

ТАБЛИЦЫ
«Цеха / Min–Max»: общий объём, количество нарядов, сотрудников и минимум/
максимум по дням, месяцам, годам с датами соответствующих значений.
«Подразделения»: объём и Min–Max по подразделению. «Работы / коды» и
«Работы подразделений»: объём по виду продукции/работе и её коду.
«По месяцам», «По годам», «Сотрудники на сменах»: уникальные сотрудники
за период и выходы. Гистограмма может показывать людей, выходы или кг.
Один выход — ФИО + цех + дата + смена, независимо от количества строк.
«Мастера», «Выработка мастеров»: наряды, где мастер указан в шапке, правки,
показатели смен и Min–Max. Фактический автор сохранения — отдельный логин.
«Логины / сессии программы»: создания, правки и время открытого приложения
пользователями. Производственные работники в приложение не входят; для них
сеансы не создаются. Время сеанса включает бездействие; авария ограничивается
последним heartbeat, без выдумывания продолжительности после него.

Двойной щелчок по сотруднику открывает его профиль, строки, работы за полный
год, Min–Max каждой работы по месяцам и наиболее частые подразделения.
Внутри есть выбор цеха, года, выбранного периода или полного года.
Двойной щелчок по цеху, подразделению, работе или мастеру открывает отдельный
срез: дни, месяцы, годы, работы, смены и численность сотрудников.

ГРАНИЦЫ РАСЧЁТОВ
Производство считается по последней версии; правки не умножают объём.
Дата производства — дата наряда, дата создания/правки — дата сохранения.
Min–Max берётся по зарегистрированным периодам с нарядами. Отсутствие записи
не доказывает нулевую выработку. Нулевые месяцы гистограммы обозначают
отсутствие зарегистрированных выходов в выбранном срезе.
Помесячные/годовые суммы основной таблицы ограничены выбранными датами.
Отдельные годовые таблицы профиля охватывают полный календарный год.
Объём сырья пока представлен существующим итоговым ФИКС весом по строкам:
отдельного поля фактически поступившего сырья/идентификатора партии нет.
Если одинаковый общий вес партии повторён у нескольких сотрудников,
это несколько введённых строк; программа не угадывает, какую удалить.
Часы по строкам не доказывают время присутствия сотрудника на предприятии.
Между цехами сотрудники сопоставляются по полному ФИО; однофамильцев с
одинаковыми ФИО нужно различать в справочниках.
Каждая база читается в согласованной транзакции; общей транзакции между
шестью SQLite-базами нет. Удалённые из БД записи не входят в текущий отчёт.

EXCEL
Кнопка «Экспорт в Excel», опция «Графики в Excel». В книге таблицы срезов,
детализация исходных количеств и единиц, Min–Max, выходы и редактируемые
диаграммы Excel. В профилях есть экспорт своего среза.
Числа сохраняются числами; названия с началом «=» не становятся формулами.

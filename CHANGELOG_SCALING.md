# SmartOrder 1.0 — исправление масштабирования

Изменения в этой версии:

- Основная вкладка «Наряд» перестроена на адаптивные `ResponsiveGrid`-компоновки. Фильтры и кнопки автоматически переходят на 1–4 колонки при изменении ширины окна.
- Страница «Наряд» и административные страницы получили вертикальную/горизонтальную прокрутку при нехватке места, без налезания элементов.
- Масштаб применяется от исходного шрифта, поэтому последовательности 200% → 100% и 150% → 100% не накапливают увеличение. Значение сохраняется в локальных настройках.
- Высоты кнопок и полей рассчитываются от масштаба; подписи таблиц и списки используют однострочный текст с `elide` вместо переноса.
- Добавлена headless-проверка `tools/check_scaling.py` для матрицы размеров окна и значений масштаба.
- Импорт XLSX/CSV ограничен по размеру, количеству элементов, строк, столбцов и длине ячеек; параметры scrypt и ввод логина/пароля проверяются до тяжёлых операций.

Проверки в среде сборки:

```text
python -m compileall -q smartorder tools
```

Полный GUI-прогон запускается на машине с PyQt5:

```text
QT_QPA_PLATFORM=offscreen python tools/check_scaling.py --strict
```

## Формат патча обновления

Администратор выбирает ZIP с двумя частями:

```text
patch.json
payload/
  smartorder/...
  resources/...
```

`patch.json` содержит как минимум `version`, а также может содержать `title`,
`description` и `previous_version`. Программа проверяет пути и размеры,
распаковывает файлы в локальную папку обновлений и записывает pending-манифест.
Базы данных в ZIP не включаются; применение файлов выполняется при следующем
перезапуске лаунчером атомарной заменой файлов с локальной страховочной копией.
При установленном флажке «Оповестить пользователей» рядом с сетевым корнем
создаётся `UPDATE_ANNOUNCEMENT.json`. У пользователей он появляется в кнопке
уведомлений и открывает общий экран «Новости обновлений».

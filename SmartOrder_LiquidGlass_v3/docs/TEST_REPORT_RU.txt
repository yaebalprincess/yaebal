SMART ORDER · ВЕРСИЯ 1.0 · ПРОВЕРКА 09.10.2026

Среда: Linux, Python 3.12.14, PyQt5 5.15.11 / Qt 5.15.2,
openpyxl 3.1.5. Интерфейс проверен с QT_QPA_PLATFORM=offscreen.
Все данные проверок временные и вымышленные; рабочие базы не использовались.

Автоматические проверки: 185 passed.
Есть одно предупреждение openpyxl об отсутствии стандартного стиля в
существующем шаблоне экспорта. Проверка чтения книги и заголовков прошла.

ПЯТЬ ПОЛЬЗОВАТЕЛЕЙ
Пять независимых процессов с отдельными логинами и сеансами одновременно
создали по десять нарядов и читали общую базу. Получены 50 разных номеров,
50 сохранённых нарядов со строками, 50 читаемых файлов .sorder. Сеансы всех
пяти логинов завершены. Процессы используют одну общую файловую папку.
Отдельно пять процессов одновременно правили одну исходную версию:
одна правка сохранена как 1.1, четыре получили StaleOrderError.
В базе ровно исходный наряд и новая версия; данные не перезаписаны молча.

ОБНОВЛЕНИЕ ИНТЕРФЕЙСА
Два независимых клиента видят новый наряд и последующую версию после
проверки изменений. Искусственно замедленное чтение не блокирует таймер GUI.
Отображение 50 000 строк аналитики использует модель таблицы; переключение
вкладок не переустанавливает глобальную таблицу стилей.
Проверены начальная тёмная тема и ленивое открытие Администрирования,
профили, поиск внутри списков, период, актуальный счётчик за сегодня.
Три кнопки управления окном: проверены видимость, контраст, выравнивание
с краем, сворачивание, разворачивание/восстановление и закрытие в обеих темах.
Проверена маршрутизация Windows hit-test к кнопкам у верхнего/правого края,
с отдельным смещением клиентской области и отрицательными координатами
экрана; Win32-API в этом тесте заменён моделью, реальная Windows не запускалась.
Столбцы нарядов: заголовки, длинное ФИО мастера и название подразделения
помещаются без ручного изменения ширины при масштабе 100, 150 и 200%.
Нажатие «Создать наряд» отслеживается фильтром событий показа: появляется
только один редактор в нужной теме и размере, без отдельной кнопки-окна.
Скрытые диалоги и календари не получают Win32-окно от смены темы.
Работа с новостями проверена при пустом файле, последующем изменении и
замене файла редактором. Пустое окно не содержит служебного текста.

ФАЙЛЫ НАРЯДОВ
Проверены атомарная очередь вместе с сохранением наряда, откат транзакции,
повтор после недоступности файла, создание копий ранее существовавших
нарядов, структура Цех / год-месяц / день и отдельные версии.
Проверены права цеха и целостность файла. Изменённая копия не подменяет
данные живого наряда: редактор получает соответствующую запись базы.
Проверена передача имени файла уже запущенному приложению через локальный
канал, открытие обычного редактора, создание версии 1.1 и экспорт из него.

ОСТАЛЬНЫЕ ПРОВЕРКИ
Миграция шести цехов, разграничение доступа, единицы ФАКТ, суммы и
Min–Max, объединённая ФАКТ Оплата, сессии реальных пользователей,
уведомления мастерам, блокировки редактирования, история и архивы.

СКВОЗНОЙ ЗАПУСК main()
Вход, главное окно, шесть баз, 43 последних наряда, 129 строк,
три разных ФИО, отчёт Excel с шестью диаграммами.
Диагностика показывает два активных экземпляра; у мастера одно уведомление.
Ошибок сценария нет. Изображения и Excel лежат в demo.

ГРАНИЦЫ ПРОВЕРКИ
Параллельные процессы проверены на локальной файловой системе Linux.
Реальные Windows/SMB-блокировки, сборка PyInstaller/C#, UAC/NTFS,
отрисовка/взаимодействие заголовка и DPI Windows здесь не исполнялись.
Их нужно проверить на вашей Windows и сетевой папке после сборки.
Три кнопки теперь всегда рисуются в видимой верхней строке со стандартными
символами: их видимость не зависит от DWM за непрозрачной панелью Qt.
Фон и цвет символов соответствуют светлой/тёмной теме. Операции окна
выполняются через Qt, а Windows sizing-frame остаётся для границ и тени.
Оригинальные GIF, значок и логотип отсутствовали в загруженном архиве:
Windows-сборка использует вашу прежнюю папку resources и проверяет GIF/ICO.

Повторить в среде разработки:
  pip install -r requirements-dev.txt
  QT_QPA_PLATFORM=offscreen python -m pytest -q
  QT_QPA_PLATFORM=offscreen python tools/smoke_desktop.py --output-dir ./demo

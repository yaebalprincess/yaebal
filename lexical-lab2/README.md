# Лабораторная работа № 2 — лексический анализатор, вариант 6

Вариант 6 требует анализировать логические выражения, разделённые `;`. Допустимы идентификаторы, константы `0` и `1`, присваивание `:=`, операции `or`, `xor`, `and`, `not` и круглые скобки.

Готовые материалы:

- `lab2_variant6_report.pdf` — оформленный отчёт с заданием, КС-грамматикой в форме Бэкуса—Наура, описанием алгоритма, графом ДКА, результатами тестирования, текстом программы и выводами;
- `lab2_variant6_report.docx` — редактируемая версия отчёта;
- `lab2_lexer.py` — программа-сканер без внешних зависимостей;
- `test_lexer.py` — 4 модульных теста;
- `dfa.dot`, `dfa.svg`, `dfa.png` — исходник и изображения конечного автомата;
- `valid_variant6.txt`, `errors_variant6.txt` — корректный и ошибочный тестовые файлы;
- `*_tokens.csv`, `*_result.txt` — результаты тестового запуска;
- `lab2_variant6.zip` — архив всего задания.

## Запуск

```bash
python lab2_lexer.py valid_variant6.txt --csv tokens.csv --json result.json
python lab2_lexer.py errors_variant6.txt
python -m unittest -v test_lexer.py
```

Код возврата программы: `0`, если ошибок нет; `1`, если найдены лексические ошибки; `2`, если входной файл не удалось прочитать. Комментарии имеют форму `{ ... }`, могут занимать несколько строк и не попадают в таблицу лексем. Идентификатор начинается с латинской буквы, затем может содержать латинские буквы, цифры и `_`; длина ограничена 32 символами. Зарезервированные операции распознаются в нижнем регистре.

Сканер выполняет только лексический анализ. Баланс скобок, порядок операций и корректность синтаксических конструкций относятся к синтаксическому анализатору и в эту лабораторную работу не входят.

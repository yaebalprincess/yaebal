# Smart Order v11 · проверка от 12.11.2026

Версия 1.0.11, база выпуска — опубликованная v10. Архив содержит исходники и скрипты сборки Windows.

Основной прогон: **124 passed**. После финальной правки размеров справки и календаря повторены **12 UI-проверок**; дополнительно проверены английские подписи календаря и полный сценарий мастера — **3 passed**. Повторные прогоны входят в набор основных сценариев и не прибавляются к числу уникальных проверок.

Среда: Python 3.12, PyQt5 5.15, Qt offscreen в Linux. Предупреждение pytest относится к устаревшему имени `CallSpec2` в установленном плагине AnyIO.

| Требование | Проверка |
|---|---|
| Убрать выгрузку и печать из редактора | В создании и редактировании этих кнопок нет. Оставшиеся пять кнопок имеют общий нижний уровень. Разделённая кнопка в главном списке сохранена |
| Календарь как в главном меню | Один `calendar.js`, общий CSS и одинаковая разметка сетки; 42 дня, выбор даты и подтверждение через мост Qt. Проверены оба редактора, русский и английский интерфейс |
| Читаемая помощь и обучение | Непрозрачная поверхность в двух темах; одинаковый размер книги и уведомлений; отдельное окно с заголовком и «Начать!»; F1 открывает справку раздела |
| Настоящие шаги мастера | Нажатие «Создать наряд», календарь, списки смены/мастера/подразделения, подбор работника и работы, ввод часов/коробок/веса, сохранение, исправление, подробная история, доступное администрирование. Переход происходит после действия |
| Изоляция учебных данных | Полный сценарий под учётной записью мастера завершается без рабочих нарядов и черновиков. Создание через основной обработчик и HTML-мост во время обучения направляется в учебный сценарий |
| Качественные значки | Колокольчик рисуется контуром через `QIconEngine`, пустое состояние — `QSvgRenderer`; проверена сглаженная отрисовка значка при размерах 20, 40 и 80 пикселей |
| Меню цехов без отдельного окна | Открытие не добавляет видимых окон верхнего уровня. Меню находится внутри главного окна, закрывается при нажатии вне него или Escape |
| Защита первого кадра | Непрозрачная поверхность цвета темы остаётся до первого заполненного кадра Chromium. Загрузка цеха завершается после кадра и чтения списка; светлая заставка после авторизации повторно не показывается |
| Рамка и перетаскивание | Повторная настройка одной и той же рамки не вызывает `SetWindowPos`. Геометрия после перетаскивания сохраняет доступный заголовок, включая монитор с отрицательными координатами и верхнюю панель задач |

В общий прогон также входят сохранение и версии нарядов, справочники и авторы, роли и индивидуальные права, черновики между запусками, Excel и печатный PDF, темы, масштаб, фильтры и переключение цехов. Проверены синтаксис Python и JavaScript, отсутствие ошибок `git diff --check`.

## Граница проверки на Windows

Нативный запуск Windows после авторизации, анимация Windows Snap, физическое перетаскивание к панели задач и драйвер принтера в этой среде не запускались. Для рамки проверено число вызовов через подмену Win32 API, для перетаскивания — расчёт рабочей области. Ограничение геометрии подключено к `WM_EXITSIZEMOVE`; физический цикл системного перемещения Windows не воспроизводился.

Готового EXE в архиве нет. Сборка выполняется через `BUILD.cmd` с исходной папкой `resources` вашей установки. Окна авторизации и первого запуска сохранены. Круговая анимация смены темы остаётся отключённой.

Архив содержит **исходники и скрипты сборки**, без готового Windows EXE.

## Изменения v11

- В редакторах создания и исправления наряда убраны выгрузка и печать. Разделённая кнопка остаётся в главном списке сохранённых нарядов.
- Календарь редактора использует тот же HTML, CSS и код выбора дат, что и главное окно, с учётом темы и масштаба.
- Книга открывает непрозрачное читаемое окно «Обучение: как работать с нарядами?» с кнопкой «Начать!». Обучение проходит через нажатия настоящих элементов и ввод данных: создание, дата и списки, работник, работа, часы, объём, сохранение, исправление, история и доступное мастеру администрирование. Подсветка нумерована и пульсирует рябью. Учебные данные остаются во временной базе. F1 открывает справку по разделу.
- Книга и уведомления имеют одинаковый размер. Колокольчик рисуется контуром, без эмоджи. Значки и пустое состояние сотрудников рисуются векторно при нужном разрешении.
- Меню цехов открывается внутри главного окна без отдельного окна Windows и повторной перестройки рамки.
- После авторизации окно загрузки остаётся до первого заполненного кадра. Основной интерфейс и браузерная поверхность получают цвет темы заранее.
- После перетаскивания оконного режима за нижний край экрана заголовок возвращается в доступную область монитора. Привязка Windows к верхнему краю и разворачивание сохраняются.

## Сохранённые изменения v10

- В создании и редактировании наряда работы переносятся по строкам, часы и семизначный код занимают узкие столбцы. Таблица помещается в окно без горизонтального скролла. Крайний столбец оплаты заполняет свободное место; ручные пропорции остальных столбцов сохраняются в профиле для всех нарядов.
- Двойной щелчок по ячейке работы открывает подбор работ; режим «Отдельный работник» использует кнопку добавления.
- Нажатие записи истории открывает конкретную версию: автор, время, изменения сведений о смене, добавленные и удалённые работы, старые и новые часы, расценки и объёмы. Сравнение использует сохранённые снимки наряда.
- Рядом с колокольчиком — значок руководства. Он и F1 открывают справку по текущему разделу с отдельной кнопкой полного руководства. При первом входе мастеру предлагается обучение; администратор может запустить его для проверки. Учебный пример работает во временной базе и показывает только доступные действия мастера.
- Кнопка выгрузки поделена на равные части: Excel и прямая печать. Печать открывает штатный диалог с принтером по умолчанию, использует Times New Roman 14 и альбомный A4, вмещая все столбцы по ширине. Длинный наряд занимает несколько страниц. Кнопка находится в списке нарядов; требуется право выгрузки.
- В номенклатуре, работниках, мастерах и подразделениях дата создания и дата изменения отображаются над именами авторов в разделённых ячейках. Добавление, импорт и редактирование сохраняют авторов; для старых записей без этих сведений отображается «Автор не указан».

## Сохранённые изменения v9

- Создание, редактирование и продолжение черновика используют общий редактор. Метка режима редактирования пульсирует справа в шапке. Изменения сохранённого наряда создают следующую версию.
- Импорт и выгрузка открывают системный выбор файла Windows. Окно загрузки цеха затухает после загрузки данных.
- «Несохранённые черновики» в колокольчике показывают общее количество собственных черновиков в доступных цехах. Нажатие открывает список, крестик скрывает напоминание в локальном профиле до появления нового черновика.
- Вкладки рисуются со сглаженными краями. Календарь периода использует светлую или тёмную палитру, а подпись показателя расположена под кольцевой диаграммой. Колёсико прокручивает страницу персонализации без изменения размера шрифта.
- Методика показывает примеры расчёта прямо в окне аналитики. «О приложении → Как работать в программе?» открывает локальное руководство с навигацией и четырьмя снимками учебного примера.
- Esc и F11 меняют системный режим окна один раз. После изменения размера предыдущий кадр затухает внутри окна, затем видна подсказка текущего режима. Светлая и тёмная темы переключаются напрямую.

## Возможности v7

- У переключателя темы нажимается вся поверхность. Смена темы обновляет видимые элементы без замены общего стиля всех вкладок.
- Названия вкладок рассчитываются по ширине текста и выбранному шрифту, в том числе при масштабе 111%. Убраны лишний контур фокуса и чёрные рамки списков. Стрелки используют палитру приложения.
- Меню цеха открывается под кнопкой пользователя. Недоступные элементы отображаются серым, курсор над ними показывает запрет.
- Роль «Аналитик» удалена из выбора. Старые назначения переходят в «Экономист» без изменения логинов, паролей и идентификаторов. Уведомления доступны экономисту. По умолчанию панель фильтров, действий и истории нарядов перекрыта прозрачной штрихованной плашкой «Недоступно»; таблица остаётся доступной для просмотра.
- В редакторе пользователя доступны индивидуальные права на вкладки и действия. При включённом флажке используются только отмеченные разрешения; при выключенном — права выбранных ролей. Проверки выполняются и перед операциями с базой. Открытые клиенты обновляют интерфейс в фоне примерно раз в пять секунд.
- Учётную запись можно создать отключённой до заданной даты и времени. После срока она активируется при следующем входе или обращении к базе. Ручное включение или отключение отменяет расписание. Время соответствует часам компьютера.
- В редакторе наряда кнопки выровнены внизу. Пустые списки нарядов, номенклатуры и сотрудников показывают крупный одноцветный значок с подсказкой по центру.
- Основной интерфейс доступен на русском, английском, испанском, казахском, французском, немецком, японском и татарском. Имена и данные справочников не переводятся.
- «Поделиться конфигом» создаёт один локальный JSON-файл с датой и открывает папку. Предыдущий экспорт в этой папке заменяется. «Загрузить конфиг…» применяет такой файл.
- «Синхронизировать конфиг с базой» сохраняет персонализацию своей учётной записи в общей базе. При входе с другого компьютера она загружается автоматически. Отправка выполняется в фоне; неотправленные изменения сохраняются локально.

Для индивидуальных прав и синхронизации профилей на всех клиентах общей базы нужна версия **v7 или новее**. Для выдачи прав нужны разрешения управления пользователями и изменения прав. Последнего активного администратора нельзя заблокировать или лишить этих разрешений.

Сохранены изменения v6: прежние окна входа и первого запуска, персонализация для всех, две темы «О приложении», расписание темы, масштаб открытой вкладки, отключённый масштаб аналитики, изменение ширины столбцов и сохранение окна при смене цеха.

## Запуск и сборка

Требуется Python 3.12 x64:

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

Сохраните настройки сетевой папки и `resources` из своей установки. Рабочие базы пользователей в архив не входят. Для сборки Windows запустите **BUILD.cmd** на Windows с исходной папкой ресурсов. `Install_and_Start_SmartOrder.cmd` запускает уже собранный выпуск.

## Персонализация на другом компьютере

Включите «Синхронизировать конфиг с базой» и дождитесь сообщения о сохранении. На другом компьютере используйте ту же общую базу и учётную запись. Флажок «Применять сохраненные настройки персонализации при запуске» определяет применение профиля при входе. Для переноса фона используйте изображение до 4 МБ; выбранные шрифты должны быть установлены на обоих компьютерах. Импорт файла не включает синхронизацию без выбора пользователя.

## Изображения цехов и прежняя GIF-тема

Оригинальные пять фотографий и GIF отсутствуют в доступных файлах репозитория; в архив они не включены. Сохраните свою папку `resources`. Окно загрузки ищет фотографии в `resources` установки и общей сетевой папки:

| Цех | Файл |
|---|---|
| Упаковки | `цех упаковки.png` |
| Коптильный | `цех копчения.jpg` |
| Сушки | `цех сушки.png` |
| Сычужный | `сычужный цех.png` |
| Адыгейский | `адыгейский цех.png` |

Для «Сырного» используется фото сычужного цеха. Без фото отображается тёмный фон с названием цеха. Прежняя тема использует `login_background.gif`, `loading2.gif` вашей установки; без GIF отображается градиент.

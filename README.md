# Smart Order · Liquid Glass v7

[Скачать ZIP исходников v7](https://github.com/yaebalprincess/yaebal/archive/refs/heads/smartorder-liquid-glass-v7.zip)

Версия находится в завершающей проверке. Обновление от 6 ноября 2026 года.

- Роль «Аналитик» убрана из выбора; прежние назначения мигрируют в «Экономист».

- Поддерживается отложенная активация. До заданной даты и времени вход отключён.
- Исправляются первый клик переключателя темы, размеры названий вкладок, рамки списков и позиция выбора цеха.
- Добавлены казахский, французский, немецкий, японский и татарский языки.

Архив содержит исходники и скрипты сборки. Для запуска и сборки используйте инструкции ниже.

# Smart Order · Liquid Glass v6

[Скачать исходники v6 ZIP](https://github.com/yaebalprincess/yaebal/archive/refs/heads/smartorder-liquid-glass-v6.zip)

Обновление интерфейса от 5 ноября 2026 года. Сохранены изменения v5: прежние
окна входа и первого запуска, отдельная персонализация для всех ролей,
две темы страницы «О приложении», расписание темы и оформление диалогов.

## Изменения v6

- Ленивые вкладки встраиваются в существующие контейнеры. Убраны вспомогательные
  графические окна размытия и повторное оформление всего приложения при масштабе.
- Во время движения ползунка масштаб не перестраивает интерфейс. После отпускания
  обновляется открытая вкладка; оформление остальных применяется при открытии.
- В аналитике масштаб всегда 100%, вместо ползунка отображается сообщение о недоступности.
- Ширину столбцов нарядов можно менять мышью и стрелками на разделителе заголовков.
  Размеры сохраняются в профиле.
- В пустых нарядах, номенклатуре и сотрудниках отображаются подсказки по центру таблицы.
- Выключенный переключатель темы означает светлую тему, включённый — тёмную.
- В персонализации доступны русский, английский и испанский языки интерфейса;
  данные базы, введённые имена и названия не переводятся. Верхний переключатель темы скрыт.
- Флажок «Применять сохраненные настройки персонализации при запуске» управляет
  применением профиля при следующем входе. При снятом флажке сохранённые настройки не удаляются.
- Сайт и текущая сессия расположены внизу страницы «О приложении».
- Кнопки добавления и загрузки Excel в сотрудниках и номенклатуре находятся в одной позиции.
- В создании пользователя оставлен один заголовок. Исправлены флажки ролей и текст
  проверки минимальной длины пароля. Колокольчик сохраняет цвет при нажатии.
- У аналитика сообщение «Недоступно» перекрывает действия с нарядами, сохраняя таблицу доступной.
- Переключение цеха сохраняет главное окно, веб-виджет и текущую сессию. База цеха
  открывается в рабочем потоке; небольшое окно загрузки поддерживает фон выбранного цеха.

## Скачать и запустить

Архив содержит **исходники и скрипты сборки**, без готового Windows EXE.
Для запуска требуется Python 3.12 x64:

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

Сохраните настройки сетевой папки и `resources` из своей установки. Данные рабочей
базы в архив не входят. Для сборки Windows запустите **BUILD.cmd** на Windows с
исходной папкой ресурсов. `Install_and_Start_SmartOrder.cmd` запускает уже собранный выпуск.

## Изображения цехов и прежняя GIF-тема

Пять фотографий из сообщения пользователя отсутствуют среди доступных файлов
репозитория и поэтому **не включены в этот архив**. Окно загрузки уже сопоставляет
каждому цеху оригинальное имя файла. Поместите фотографии в папку `resources`
рядом с программой либо в `resources` общей сетевой папки:

| Цех | Файл |
|---|---|
| Упаковки | `цех упаковки.png` |
| Коптильный | `цех копчения.jpg` |
| Сушки | `цех сушки.png` |
| Сычужный | `сычужный цех.png` |
| Адыгейский | `адыгейский цех.png` |

Без фотографии используется тёмный фон с названием цеха. Для цеха «Сырный»
используется фото сычужного цеха. Подробности — [имена ресурсов](docs/WORKSHOP_BACKGROUNDS_RU.txt).

Оригинальные `login_background.gif`, `loading2.gif` и значок приложения также
отсутствовали в исходном репозитории v4/v5. Прежняя тема использует файлы из
`resources` вашей установки; без GIF отображается градиент.

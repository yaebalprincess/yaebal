## Обучение мастера

- На первом шаге подсвечивается кнопка «Создать наряд». Рядом видны пульсирующая цифра 1 и карточка с кнопкой «Завершить обучение». Размытие фона уменьшено вдвое. Лазурная рамка повторяет контур выбранного элемента.
- При выборе сотрудника или работы подсвечиваются вся строка и кнопка «ОК». Вопрос о завершении обучения открывается в окне со сглаженными углами.
- После первого сохранения в списке виден учебный наряд. Шаг 12 выделяет его строку и кнопку «Редактировать». В редакторе подсказка находится под сотрудником, а подсветка показывает поля и ячейки, доступные для изменения.
- После второго сохранения шаг 15 указывает на «Историю редактирований». Нажмите на неё, чтобы увидеть автора, время и изменения учебного наряда. [Шаг 1](smartorder/glass/assets/guide/training.jpg) · [Шаг 12](docs/LiquidGlass_v13_Edit_action.jpg) · [Шаг 13](docs/LiquidGlass_v13_Editable_cells.jpg) · [Шаг 15](docs/LiquidGlass_v13_History.jpg)
- В администрировании под статусом мастера появилась строка «Обучение». Квадрат ■ отмечает полное прохождение курса. Квадрат □ означает, что общей базе пока неизвестно о прохождении. Предыдущие версии дату завершения не записывали.

## Тема и смена пользователя

Рамка и список нарядов получают выбранную тему за одно переключение. Программа повторно использует изображение фона и обновляет при пульсации только область вокруг номера шага. На стенде Linux с Qt 5.15.2 время от нажатия до совпадения темы рамки и списка составило 74 мс по медиане восьми переключений. В версии 1.0.12 на том же стенде медиана составляла 494 мс.

В меню справа сверху выберите «Сменить пользователя». После ответа «Да» откроется окно авторизации. Ответ «Нет» оставляет текущую сессию открытой.

## Запуск и сборка

Для запуска из исходников в Windows с Python 3.12 x64 выполните

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

Для сборки распакуйте архив в отдельную папку, поместите рядом с `BUILD.cmd` оригинальную папку `resources` из своей установки и запустите `BUILD.cmd`. Собранная программа появится в `release/SmartOrderApp`.

Скриншоты сделаны в учебной базе. Проверки выполнялись на Linux с QtWebEngine 5.15.2 и встроенным Chromium 83. Плавность на целевом компьютере с Windows зависит в том числе от видеодрайвера и отдельно здесь не измерялась.

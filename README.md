# Smart Order · Liquid Glass v5

Исправления интерфейса и персонализация профиля от 5 ноября 2026 года.

- Вход и первый запуск используют прежний вид и обычную рамку окна. GIF входа сохраняется.
- После «Аналитики» появилась вкладка «Персонализация», доступная всем пользователям.
- В ней доступны шрифты с примерами названий окон, фон, переключатель темы,
  расписание светлой темы с 08:00 до 17:00 по времени компьютера и два варианта страницы «О приложении».
- Галочка «Сохранять персонализацию в моём профиле» хранит настройки отдельно для
  каждой учётной записи на этом компьютере. Если снять галочку, настройки действуют
  до выхода. Переключение цеха не сбрасывает их в текущей сессии.
- Закрытые списки шрифтов не меняются колёсиком мыши.
- Убрано повторное оформление всего дерева при переключениях; вкладки встраиваются
  в существующие контейнеры. Внутренние окна списков Qt не превращаются в стеклянные диалоги.
- У наряда есть такие же кнопки свернуть / развернуть / закрыть, как у главного окна.
- Исправлены заголовок создания пользователя, фильтры журнала и видимость сообщения о резервной копии.
- Цехи и резервные копии используют одноцветные значки в палитре программы.

## Скачать и запустить

Это исходники с файлами запуска и сборки, без готового Windows EXE.

Для работы с собственной базой требуется Python 3.12 x64:

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

Сохраните прежние настройки сетевой папки и папку `resources` из своей установки.
Исходные `login_background.gif`, `loading2.gif` и значок приложения не входили
в архив v4 и отсутствуют в репозитории. Для прежней GIF-темы используются эти
оригинальные файлы. Без GIF при запуске из исходников отображается градиент.

Для сборки Windows запустите **BUILD.cmd** на Windows с исходной папкой ресурсов.
Скрипт сборки проверяет наличие оригинальных GIF и значка. `Install_and_Start_SmartOrder.cmd`
устанавливает уже собранный выпуск; запускать его до сборки не нужно.

Для просмотра на временной базе запустите **PREVIEW_LIQUID_GLASS.cmd** или:

```powershell
py -3.12 tools/preview_liquid_glass.py --tab personalization --theme dark
```

Новая вкладка поддерживается параметром `--tab personalization`.

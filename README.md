# Установка и демонстрация SVN

[Скачать видео MP4 (56 секунд)](./svn-demo.mp4?raw=true)

Видеозапись реального терминального сеанса на Debian Linux с Apache Subversion 1.14.5.

В демонстрации: загрузка и локальная установка сервера и клиента из подписанного репозитория Debian, создание хранилища, настройка аутентификации и прав доступа, запуск `svnserve`, две рабочие копии, добавление файла, два коммита, получение изменений и просмотр истории.

Сервер доступен только на локальном интерфейсе. Используется отдельный учебный пользователь; пароль в видео не показывается.

# Smart Order · Liquid Glass v7

[Скачать ZIP v7](https://github.com/yaebalprincess/yaebal/archive/refs/heads/smartorder-liquid-glass-v7.zip)

Версия программы **1.0.7**, обновление от **6 ноября 2026 года**.
Архив содержит **исходники и скрипты сборки**, без готового Windows EXE.

## Изменения

- У переключателя темы нажимается вся поверхность. Смена темы обновляет видимые элементы и не заменяет общий стиль всех вкладок. Локальный замер с открытыми вкладками: 0,046–0,048 секунды; это не замер на Windows.
- Названия вкладок рассчитываются по ширине текста и выбранному шрифту, в том числе при масштабе 111%. Убраны лишний контур фокуса и чёрные рамки списков. Стрелки используют палитру приложения.
- Меню цеха открывается под кнопкой пользователя. Недоступные элементы отображаются серым, курсор над ними показывает запрет.
- Роль «Аналитик» удалена из выбора. Старые назначения переходят в «Экономист» без изменения логинов, паролей и идентификаторов. Уведомления доступны экономисту. По умолчанию панель фильтров, действий и истории нарядов перекрыта прозрачной штрихованной плашкой «Недоступно»; таблица остаётся доступной для просмотра.
- В редакторе пользователя доступны индивидуальные права на вкладки и действия. При включённом флажке используются только отмеченные разрешения; при выключенном — права выбранных ролей. Проверки выполняются и перед операциями с базой. Открытые клиенты обновляют интерфейс в фоне примерно раз в пять секунд.
- Учётную запись можно создать отключённой до заданной даты и времени. После срока она активируется при следующем входе или обращении к базе. Ручное включение или отключение отменяет расписание. Время соответствует часам компьютера.
- В редакторе наряда кнопки выровнены внизу. Пустые списки нарядов, номенклатуры и сотрудников показывают крупный одноцветный значок с подсказкой по центру.
- Переключение полноэкранного и оконного режима использует короткий переход геометрии, сохраняет прежний размер и не создаёт вспомогательных прозрачных окон.
- Основной интерфейс доступен на русском, английском, испанском, казахском, французском, немецком, японском и татарском. Имена и данные справочников не переводятся.
- «Поделиться конфигом» создаёт один локальный JSON-файл с датой и открывает папку. Предыдущий экспорт в этой папке заменяется. «Загрузить конфиг…» применяет такой файл.
- «Синхронизировать конфиг с базой» сохраняет персонализацию своей учётной записи в общей базе. При входе с другого компьютера она загружается автоматически. Отправка выполняется в фоне; неотправленные изменения сохраняются локально.

Для индивидуальных прав и синхронизации профилей **обновите все клиенты общей базы до v7**: старые версии не учитывают новые разрешения. Для выдачи прав нужны разрешения управления пользователями и изменения прав. Последнего активного администратора нельзя заблокировать или лишить этих разрешений.

Сохранены изменения v6: прежние окна входа и первого запуска, персонализация для всех, две темы «О приложении», расписание темы, масштаб открытой вкладки, отключённый масштаб аналитики, изменение ширины столбцов и сохранение окна при смене цеха.

## Запуск и сборка

Требуется Python 3.12 x64:

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

Сохраните настройки сетевой папки и `resources` из своей установки. Рабочие базы пользователей в архив не входят. Для сборки Windows запустите **BUILD.cmd** на Windows с исходной папкой ресурсов. `Install_and_Start_SmartOrder.cmd` запускает уже собранный выпуск.

## Персонализация на другом компьютере

Включите «Синхронизировать конфиг с базой» и дождитесь сообщения о сохранении. На другом компьютере используйте ту же общую базу и учётную запись. Флажок «Применять сохраненные настройки персонализации при запуске» определяет применение профиля при входе. Для переноса фона используйте изображение до 4 МБ; выбранные шрифты должны быть установлены на обоих компьютерах. Импорт файла не включает синхронизацию без выбора пользователя.

## Изображения цехов и прежняя GIF-тема

Оригинальные пять фотографий и GIF отсутствуют в доступных файлах репозитория; в архив они не включены. Сохраните свою папку `resources`. Окно загрузки ищет фотографии в `resources` установки и общей сетевой папки:

| Цех | Файл |
|---|---|
| Упаковки | `цех упаковки.png` |
| Коптильный | `цех копчения.jpg` |
| Сушки | `цех сушки.png` |
| Сычужный | `сычужный цех.png` |
| Адыгейский | `адыгейский цех.png` |

Для «Сырного» используется фото сычужного цеха. Без фото отображается тёмный фон с названием цеха. Прежняя тема использует `login_background.gif`, `loading2.gif` вашей установки; без GIF отображается градиент.

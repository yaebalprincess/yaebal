# Viper Control

Локальная утилита на русском языке для проводной Razer Viper 8KHz (USB VID 1532, PID 0091) и Windows 10 версии 1607 или новее, x64. Работает через встроенный HID-драйвер Windows. Права администратора и установка службы не требуются. После закрытия окна процесс завершается.

## Запуск

Распакуйте архив ViperControl-Windows-x64.zip и запустите ViperControl.exe. Подключите мышь и закройте другие программы, которые меняют её настройки. При запуске утилита читает ступени и текущий DPI. Чтобы обновить показания после нажатия кнопки на мыши или её переподключения, нажмите F5.

## Чувствительность и память

На вкладке **Производительность** выберите от одной до пяти ступеней и отметьте активную. Для каждой ступени доступны значения от 100 до 20 000 DPI. Снимите галочку «Одинаковый DPI по осям X и Y», если нужны разные значения. Доступные частоты опроса — 125, 500, 1000, 2000, 4000 и 8000 Гц.

Кнопка **Записать в мышь** передаёт таблицу с признаком сохранения в памяти устройства и устанавливает выбранную частоту. Программа перечитывает ступени, текущий DPI и частоту для проверки. На вкладке **Память** можно сравнить таблицу редактора с последними показаниями мыши, отдельно прочитать или изменить текущие X/Y и восстановить заводские ступени 400, 800, 1600, 2400 и 3200 DPI с активной третьей ступенью.

**Очистить память…** запускает отдельную операцию. Программа запрашивает подтверждение, проверяет сведения о хранилище, удаляет пользовательские слоты и передаёт команду форматирования. Базовый слот 1 сохраняется. Пользовательские профили и макросы могут быть потеряны без возможности восстановления. Для копии назначений кнопок и макросов заранее экспортируйте их через Synapse. Файл .viper хранит только параметры, которые поддерживает Viper Control. Полный заводской сброс также доступен в Synapse. [Инструкция Razer](https://mysupport.razer.com/app/answers/detail/a_id/14741)

## Другие вкладки

- **Настройка** сохраняет параметры мыши в локальный файл .viper (Ctrl+S) и открывает профиль (Ctrl+O). При импорте значения попадают в редактор. Для записи выберите нужную вкладку и нажмите кнопку применения.
- **Подсветка** задаёт яркость логотипа и встроенные эффекты, в том числе статический цвет, спектр, дыхание и реакцию на нажатие. Яркость можно считать с мыши. Эффект и цвета для редактирования берутся из локального профиля.
- **Калибровка** задаёт дистанцию отрыва и возврата. Для Smart Tracking предусмотрена проверка режима сенсора. Для ручного режима доступны проверенные комбинации уровней. После отключения питания может потребоваться повторное применение.
- **Windows** читает и меняет скорость указателя, повышенную точность, основную кнопку, параметры колеса, след указателя и другие параметры текущего пользователя. Для записи системных изменений нажмите кнопку применения на этой вкладке.

## Совместимость и проверки

В этой версии отсутствуют редактор назначений кнопок и макросов, Chroma Studio и управление содержимым каждого из пяти аппаратных профилей по отдельности. Протокол HID, проверенные настройки устройства и источники описаны в [PROTOCOL.md](PROTOCOL.md).

Windows x64 EXE собран статически с MinGW-w64. Запуск, все шесть вкладок, сохранение и загрузка профиля, отмена сброса и обработка отсутствующей мыши проверены в Wine. Команды тестировались программно и сверялись с опубликованными USB-записями и материалами для модели 0091. Физический экземпляр мыши для проверки этой сборки, включая сохранность после отключения питания и реальную очистку памяти, не использовался.

Для самостоятельной сборки в Linux установите g++-mingw-w64-x86-64 и запустите bash build.sh. Готовый EXE появится в ../build.

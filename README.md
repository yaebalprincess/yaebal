# Smart Order · Liquid Glass v12

[Скачать ZIP v12](https://github.com/yaebalprincess/yaebal/archive/refs/heads/smartorder-liquid-glass-v12.zip)

Версия **1.0.12**, 17 ноября 2026 года. ZIP содержит исходники и скрипты сборки Windows, без готового EXE.

## Что изменилось

- Внизу редактора наряда, сразу справа от «Удалить выбранных», добавлена кнопка **«Столбцы по умолч.»**. Она возвращает исходную ширину столбцов и сохраняет этот выбор для следующих нарядов. Перенос работ, узкие часы и семизначный код, заполнение крайнего столбца и ручная настройка сохранены.
- В меню пользователя справа сверху есть **«Сменить аккаунт»**. Вопрос «Вы уверены, что хотите выйти из аккаунта?» открывается по центру. «Нет» оставляет текущую сессию; «Да» завершает её и открывает прежнюю авторизацию с пустыми полями. Новый вход загружает права и персонализацию новой учётной записи.
- **Прямая печать полностью удалена**: кнопки, обработчики и модуль печати. В главном списке снова одна кнопка «Выгрузить в Excel».
- Начало и завершение обучения, подсказки и кнопки используют увеличенный читаемый шрифт. Текст переносится; при маленьком окне прокручивается текст подсказки, а кнопки остаются доступны.
- Подсказки главного списка рисуются в том же HTML-слое, что и наряды. Нативное затемнение не перекрывает прямоугольник Chromium. Выделяется текущий элемент, остальная область затемняется и размывается. Вложенный выбор работников/работ сохраняет затемнение редактора и основного окна.
- Подсказка даты находится под полем даты. После ввода часов, количества коробок и веса переход выполняется кнопкой **«ОК»** в подсказке; клавиша Enter только завершает ввод в ячейке. «Завершить обучение» и отмена редактора запрашивают подтверждение «Да» / «Нет».
- Для редактирования обучение возвращает в главный список: там виден только учебный наряд и подсвечена кнопка «Редактировать» (шаг 12 стандартного курса мастера). Затем нужно изменить любые данные, нажать «ОК», сохранить и открыть учебную историю. Реальные наряды возвращаются после завершения. Учебные наряды и черновики не записываются в рабочую базу.
- Убраны захват кадров Chromium и затухающие снимки при смене вкладок. Браузерная поверхность остаётся непрозрачной и получает изображение того же фона, что и основной интерфейс, без повторного захвата окна при каждом нажатии.
- В «О приложении» под тремя колонками добавлено предупреждение об эпилепсии. Предупреждение и нижняя панель Powered by оформлены стеклянными панелями в обеих темах; ссылка и счётчик сессии сохранены.

## Запуск и сборка

Нужен Python 3.12 x64:

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

Для Windows-сборки запустите **BUILD.cmd**. Сохраните свою исходную папку `resources` с фотографиями цехов, GIF, логотипами и значком приложения: исходный репозиторий не содержит этих оригинальных файлов. Рабочие базы и настройки общей сетевой папки в ZIP не включены.

Проверки выполнены на Linux с Qt offscreen и настоящим Chromium из PyQtWebEngine. Визуальную плавность и отсутствие чёрных кадров на конкретном Windows/GPU нужно проверить после сборки на целевом ПК. Это ограничение среды проверки; подробности и результаты — в отчёте выше.

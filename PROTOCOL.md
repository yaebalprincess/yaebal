# Память и калибровка Viper 8KHz

Поддерживается проводная Razer Viper 8KHz (RZ01-03580, USB VID 1532, PID 0091). В мыши пять аппаратных слотов, включая базовый. Пять ступеней DPI внутри набора настроек переключаются отдельно. Вкладка «Память» показывает занятые слоты по ответу самой мыши. [Руководство Razer на русском](https://dl.razerzone.com/master-guides/RazerSynapse3/VIPER8KHZ-00000145-ru.pdf)

## Очистка встроенной памяти

Команда удаляет пользовательские слоты 2–5 и форматирует область хранения макросов. Базовый слот 1 защищён производителем от команды удаления. Эта операция необратима. Файл Viper Control содержит настройки программы. Чтобы сохранить назначения и макросы, экспортируйте нужные профили через Synapse перед очисткой мыши. [Экспорт профилей Synapse](https://mysupport.razer.com/app/answers/detail/a_id/1909/~/how-to-export-and-import-profiles-and-configurations-in-razer-synapse)

Последовательность сверена с модулем Razer для этой модели, версия пакета 3.9.0331.030402. Вход Storage_Reset в RzCtl_0091.dll перечисляет профили, удаляет пользовательские слоты и запускает форматирование. В обработчике удаления предусмотрен отдельный возврат для слота 1. SHA-256 модуля — db14c6bd7b4e09c100b5fe0f0afb3546538145b37f8c7113157ad7661013997c. Для сверки в версии 24.0.0.030115 адреса RVA функций перечисления, удаления, форматирования и общего сброса равны 2EB60, 2FD00, 2ADE0 и 57500. Программа самостоятельно формирует HID-сообщения. [Пакет Razer для PID 0091](https://cdn.razersynapse.com/17095215656yPLaMPHRazer_145_0_Setup_v3.9.0331.030402.exe)

До первого удаления программа проверяет число слотов, их номера и доступность регистров флеш-памяти. Для каждого пользовательского слота она проверяет подтверждение команды удаления. Для форматирования отправляется одна команда. Завершение подтверждается отдельным чтением регистра, затем программа повторно сверяет список слотов. При ошибке возможен частичный результат. Для полного возврата к заводским настройкам Razer также предоставляет команду в Synapse 4. Откройте Viper 8KHz, нажмите «?» вверху справа, затем Reset и Delete. [Инструкция производителя](https://mysupport.razer.com/app/answers/detail/a_id/14741/~/how-to-factory-reset-razer-peripherals-in-razer-synapse-4)

## Расстояния отслеживания

Для ручных пресетов программа использует команды из USB-записей именно Viper 8KHz. Значения ручной шкалы — относительные уровни. Доступны 3, 4, 5 и 7, а для раздельного отрыва и посадки — пары 4/3, 7/3 и 8/3. Сравнение с таблицей mmdatav4.ini из пакета Razer и с положительными ответами в записях подтвердило значения. После отключения питания калибровку может потребоваться применить ещё раз. [Записи владельцев Viper 8KHz](https://github.com/openrazer/openrazer/issues/1426#issuecomment-877648691)

В режиме Smart Tracking используются миллиметры. Программа проверяет поддержку формата запросом к сенсору до записи и читает режим и расстояния после неё. Для симметричного ручного пресета прошивка подтверждает запись таблицы отдельными ответами. Мастер индивидуального сканирования коврика отсутствует. [Описание формата Focus+](https://github.com/geezmolycos/razerqdhid/blob/main/docs/cmd_sensor-en.md) · [Записи команд Synapse для сенсора Focus+](https://github.com/openrazer/openrazer/issues/783#issuecomment-651574555)


## DPI и частота опроса

Для активной таблицы DPI программа использует чтение и запись с признаком VARSTORE и сверяет ответ с редактором. Текущий DPI сенсора читается отдельным запросом. Для частоты опроса от 125 до 8000 Гц последовательность сверена с USB-трассами Viper 8KHz. Проверка обратным чтением происходит до отключения питания. [Обработка Viper 8KHz в OpenRazer](https://github.com/openrazer/openrazer/blob/ab2452847d12f4c789af040b17599012a0dd80b9/driver/razermouse_driver.c#L7636-L7646) · [Формат таблицы DPI](https://github.com/openrazer/openrazer/blob/ab2452847d12f4c789af040b17599012a0dd80b9/driver/razerchromacommon.c#L1281-L1324) · [USB-записи для Viper 8KHz](https://github.com/openrazer/openrazer/issues/1426)

## Проверка реализации

Десять последовательностей ручной настройки сверены побайтно с сохранёнными запросами Synapse и ответами Viper 8KHz. Шесть комбинаций Smart Tracking проверены с моделируемым чтением значений. Очистка протестирована на моделируемом устройстве, включая отложенное завершение, неожиданные ответы, сохранение базового слота и обрыв обмена. Физическую запись и работу после отключения питания на реальной мыши в среде сборки проверить не удалось.

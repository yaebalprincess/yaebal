# Liquid Glass v4

Изменения по шести пунктам обратной связи.

1. **Тонкая настройка шрифтов.** В администрирование добавлен блок персонализации.
   Все системные семейства доступны без ограничения по языку или моноширинности.
   Девять независимых групп: заголовок окна, подписи верхней панели, заголовки
   разделов, текст, кнопки, поля, строки таблиц, заголовки таблиц и вкладки.
   Для каждой группы задаются семейство, размер, жирность и курсив; есть образец.
2. **Настройка фона.** Стандартное изображение, однотонный фон или собственный
   файл. Выбранное изображение копируется в локальные настройки, поэтому
   перемещение исходного файла не сбрасывает оформление.
3. **Единая оболочка.** Устранено переключение между двумя полными окнами Qt и
   Chromium. Одна шапка, один масштаб, одна навигация остаются на месте во всех
   вкладках; Chromium теперь рисует только содержимое нарядов. Аналитика тоже
   использует выбранный масштаб. Настройки сохраняются при следующем запуске.
4. **Сообщение о резервной копии.** Повторяющаяся картинка заменена прозрачным
   стеклом с живой подложкой интерфейса.
5. **Официальная инструкция.** Полностью обновлены порядок работы, явный режим
   «Отдельный работник», расчёты, версии, черновики, Excel, файлы .sorder,
   аналитика и персонализация. Просмотр и PDF используют один текст. Кнопка
   скачивания заменена значком справа над «Как работать в программе?».
6. **Стеклянные окна.** Диалоги, меню, календарь, новости и выбор файлов используют
   прозрачный верхнеуровневый слой и маску скруглённого окна. Собственная шапка
   поддерживает перемещение, закрытие и разворачивание; есть изменение размера.
   Подложка берётся из окна приложения под диалогом, обновляется при перемещении
   и изменениях, размывается и получает небольшой линзовый сдвиг по краям.

Настройки оформления локальны для компьютера и выбранного сетевого корня базы.
Рабочие базы, расчёты, роли, блокировки и формат Excel не менялись.

ИСПРАВЛЕНИЯ В ЭТОЙ ПОСТАВКЕ
Свернуть, развернуть/восстановить и закрыть всегда видны справа в заголовке.
Стандартные символы управления рисуются в цвете темы, без округлых плашек.
Столбцы списка нарядов получают ширину по заголовкам и содержимому;
свободное место делится между мастером и подразделением. При увеличении
масштаба ширина пересчитывается; при нехватке места доступен скролл.
Редактор сразу показывается в окончательном размере и теме. Кнопка Excel
сразу принадлежит редактору и не появляется отдельным белым мини-окном.

Это исходники и средства сборки Windows. Готовый EXE нужно собрать на Windows.
Для сборки: Python 3.12 x64, .NET Framework 4.x и ваша оригинальная папка
resources. В исходном архиве не было GIF, логотипов и значка приложения.
Скопируйте прежние loading2.gif, login_background.gif, smartorder_app_icon.ico
и логотипы в resources рядом с main.py.

СБОРКА
1. Распакуйте архив отдельно от рабочей сетевой установки.
2. Запустите BUILD.cmd. Он использует Build_SmartOrder.ps1, устанавливает
   зависимости в локальное окружение и собирает приложение.
   BUILD.cmd разблокирует только PS1 из распакованной папки приложения.
   Общую политику Windows не изменяет. При обязательной политике AllSigned
   нужен подписанный вашим системным администратором скрипт.
3. Результат смотрите в release. Dist — промежуточный результат.
4. Для запуска используйте release\SmartOrderApp\SmartOrder.exe.
   SmartOrderApp.exe — дочерний процесс; лаунчер запускает его автоматически.
5. Для собственного пути ресурсов:
   powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Build_SmartOrder.ps1 -ResourcesDir "C:\путь\resources"

УСТАНОВКА И ОБНОВЛЕНИЕ
Сохраните резервную копию рабочих баз и закройте программу у пользователей
на время замены файлов приложения. Копируйте содержимое release в общий
сетевой корень с сохранением папки SmartOrderApp и файлов рядом с ней.
Рабочие databases, Наряды, drafts, backups и заполненный UPDATE_NEWS.txt
сохраняйте. При обновлении не заменяйте их пустыми файлами из сборки.
На каждом ПК запустите Install_and_Start_SmartOrder.cmd. Он создаёт ярлык
и регистрирует .sorder для текущего пользователя Windows, без повышения прав.
В первый раз Windows может предложить выбрать Smart Order для .sorder.

РАБОТА С СЕТЕВОГО ДИСКА
SmartOrder.exe хранит интерфейс и Qt в локальном проверенном кеше ПК.
Номенклатура, сотрудники, наряды, учётные записи и версии остаются на сервере.
Кеш разделён по сетевой папке и сборке; загруженные библиотеки не заменяются.
Используются короткие SQLite-транзакции, повтор записи при занятости и DELETE
journal. Настоящее совместное использование зависит от корректных файловых
блокировок Windows/SMB. Поставку следует проверить на вашем сетевом диске.

Одновременная работа пяти пользователей поддерживается: каждый ПК имеет
свой локальный интерфейс, пять сеансов работают с общими базами и очередями.
Журнал нарядов читает данные в фоне, проверяет изменения примерно каждые
1,5 секунды и сохраняет выбор строки при обновлении. Наряды видны в выбранном
цехе и периоде, с учётом фильтров. Во время модального редактирования список
не переключается: обновится после закрытия редактора. Одновременное сохранение
обрабатывается SQLite; устаревшая версия не может перезаписать новую.
При потере сети последнее отображение остаётся; следующая проверка повторит
чтение. Сохранение в недоступную базу не считается успешным.

ФАЙЛЫ НАРЯДОВ
Структура в сетевом корне:
  Наряды\Упаковка\2026-10\08\Наряд № 1.sorder
  Наряды\Упаковка\2026-10\08\Наряд № 1.1.sorder
  Наряды\Сыр цех\2026-10\09\Наряд № 2.sorder
Год входит в название месяца, чтобы месяцы разных лет не смешивались.
Каждая версия хранится отдельно. .sorder — текстовая UTF-8 копия шапки,
строк, исходных чисел и идентификатора версии, с проверкой целостности.
Копии публикуются в фоне после успешного сохранения в базу. Ошибка записи
файла не отменяет наряд: очередь в базе повторяет публикацию. Старые наряды
создают свои файлы при запуске обновлённой программы; большой архив требует
времени. Программа не удаляет опубликованные .sorder при очистке истории БД.

Двойной щелчок по .sorder открывает Smart Order или передаёт запрос уже
запущенной программе текущего пользователя Windows. При запуске потребуется
обычный вход. Права на цех и редактирование проверяются в программе.
Если соответствующая версия существует в базе, открываются данные базы.
Последняя версия доступна для редактирования при наличии прав и свободной
блокировки; предыдущая — для просмотра с кнопкой перехода к актуальной.
Сохранение правки создаёт новую версию и новый файл.
Если версия уже отсутствует в рабочей базе, копия открывается для просмотра
и Excel. Самовольный импорт копии или перезапись рабочей базы не выполняется.
Для открытия требуется доступ к серверу и вход в приложение; автономный
вход без базы в этой поставке не добавлен. Копии .sorder не заменяют бэкап БД.
В окне наряда есть «Выгрузить в Excel», в том числе для просматриваемой версии.

ДОСТУП
Администратор, Бухгалтер и Экономист: все цеха и аналитика.
Мастер Упаковка: Упаковка.
Мастер Коптильный Цех и Мастер Цех Сушки: Коптильный и Сушка.
Мастер Сычужный цех и Мастер Сыр цех: Сычужный и Сыр цех.
Мастер Адыгейский Цех: Адыгейский. Старый Мастер: Упаковка.
Выбор цеха — выпадающий список у логина в верхней строке.
Колокольчик мастера хранит уведомления о чужих правках и комментариях к
созданным им нарядам. Самостоятельно уведомления не всплывают.
Центр диагностики показывает активные экземпляры и отдельные логины.
После аварийного закрытия экземпляр перестаёт считаться активным по таймауту.

АНАЛИТИКА
Описание показателей, единиц, фильтров и Min–Max: docs\ANALYTICS_RU.txt.
Масштаб заблокирован только во вкладке «Аналитика», тема работает везде.
Наряды и уникальные сотрудники в строке «За сегодня» рассчитаны по дате
наряда за текущий день; выбранный цех и производственные фильтры учитываются.
Основные графики и таблицы относятся к выбранному периоду.

НОВОСТИ
В новой поставке UPDATE_NEWS.txt пустой, окно «Новости обновлений» пустое.
Введите собственный текст в этот файл в общем сетевом корне и сохраните.
Открытые окна новостей пользователей обновятся примерно за секунду,
с задержкой чтения сетевого диска. Поддерживаются UTF-8 и Windows-1251.
Текст показывается буквально; разметка HTML не исполняется.
Edit_Update_News.cmd запускает редактор с UAC администратора Windows.
Protect_Update_News.ps1 позволяет администратору настроить NTFS-права TXT:
пользователям чтение, администраторам изменение. Сетевая папка также должна
запрещать обычным пользователям удаление/замену защищённого файла.
Двойной щелчок по произвольному TXT сам по себе не вызывает UAC: это
обеспечивается редактором-помощником и правами Windows, не вкладкой программы.

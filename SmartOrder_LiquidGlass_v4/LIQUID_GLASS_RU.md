# Smart Order — Liquid Glass v4

В v4 добавлены персонализация, общая шапка и масштаб, живое стекло диалогов
и новая инструкция. Изменения перечислены в `CHANGES_LIQUID_GLASS_V4.md`.

Окно «Наряд» перенесено на HTML/CSS/JavaScript внутри Qt WebEngine (Chromium).
Python 3.12, PyQt5, существующие SQLite-базы и обработчики нарядов сохранены.
Это desktop-приложение; отдельный браузер, интернет-сайт и локальный HTTP-сервер
для нового окна не нужны.

## Быстро посмотреть

Установите Python 3.12 x64. Запустите `PREVIEW_LIQUID_GLASS.cmd`.
Он установит зависимости в отдельное окружение и откроет настоящее окно
программы на временной базе. Можно нажимать кнопки и создавать пробные наряды.
Пробная база удаляется после закрытия; рабочие данные и сохранённые настройки
пользователя при таком запуске не используются.

Если зависимости уже установлены:

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 tools/preview_liquid_glass.py
```

Для работы с существующими данными используйте штатный запуск `main.py` с вашим
обычным `SMARTORDER_NETWORK_ROOT`. Авторизация остаётся штатной.
Не переносите базы в архив исходников и не заменяйте их файлами из предпросмотра.

## Что реализовано

- Фон производства встроен в приложение. Стеклянные слои размывают фон под
  собой; текст, кнопки и строки таблицы остаются резкими.
- Верхняя панель, три системные кнопки, тема, профиль и выбор цеха.
- Исходный порядок шести вкладок, четыре фильтра, четыре основные кнопки,
  история справа и таблица снизу.
- Реальные данные, выбор строки, двойной щелчок, контекстное меню, история,
  создание, редактирование, Excel и удаление черновика.
- Масштаб 50–200%, четыре фильтра в одном ряду, прокрутка, светлая и тёмная темы.
- Фон ограничен настоящим окном; декоративного поля с картинкой снаружи нет.
- Наведение плавно направляет градиент к курсору; нажатие сопровождается
  анимацией тени и световой волной. Время перехода теней 120 мс, как в исходной программе.
- По Esc возвращена исходная анимированная подсказка полноэкранного режима,
  теперь с белым фоном и синим значком. Удержание Esc не вызывает повторных переключений.
- Списки мастеров, смен, подразделений, цехов и календарь открываются как
  полупрозрачные панели с размытием. Длинные списки поддерживают поиск и клавиатуру.
- Статус базы на странице нарядов убран. Отступы работают в Chromium 83;
  они не зависят от неподдерживаемого в этой версии flex gap.
- Остальные вкладки и диалоги используют общий стеклянный стиль Qt в том
  же главном окне. Аналитика сохраняет масштаб 100%.
- Обновления моделей поступают из существующего фонового механизма. Само
  HTML-представление не опрашивает SQLite и не сохраняет наряды самостоятельно.
- При сбое Chromium открывается стандартный интерфейс с сообщением об ошибке.

Фиксированный фон выбран по макету. Эффект не является прозрачностью всего
Windows-окна: надписи не просвечивают вместе с рабочим столом. Оптическое
преломление искажений, как в системных материалах Apple, не реализуется;
используются размытие, полупрозрачные слои, градиенты, блики и тени.

## Файлы изменения

| Файл | Назначение |
|---|---|
| `smartorder/glass_ui.py` | Chromium-представление и ограниченный Qt WebChannel-мост |
| `smartorder/glass/index.html` | Структура окна |
| `smartorder/glass/orders.css` | Стекло, темы, состояния и адаптивность |
| `smartorder/glass/orders.js` | Отображение состояния и команды пользователя |
| `smartorder/glass/glass-popovers.js` | Стеклянные списки, поиск, цеха и календарь |
| `smartorder/glass/liquid-motion.js` | Градиент под курсором и анимации нажатий |
| `smartorder/glass/assets/factory-glass.png` | Фон, подготовленный по выбранному макету |
| `tools/preview_liquid_glass.py` | Предпросмотр на временной базе |
| `tests/test_liquid_glass.py` | Проверки реальной страницы и Qt-моста |
| `tests/test_liquid_glass_v2.py` | Проверки шести исправлений интерфейса |

В `app.py` подключено новое окно и включён общий OpenGL-контекст до создания
QApplication. В `enterprise_ui.py` переключение цеха сохраняет класс нового
окна. В `heavy_ui.py` добавлен отсутствовавший импорт `QFontMetrics`, из-за
которого таймер масштабирования исходной версии мог завершать процесс.
Цвет исходного значка подсказки Esc теперь можно задать свойством `iconColor`;
в новом окне выбран синий цвет на белой панели.
Файлы `db.py`, `domain.py`, `security.py`, `workshops.py`, `excel.py` и обработчики
блокировок/сохранения не изменены.

## Windows-сборка

`requirements.txt` дополнен PyQtWebEngine 5.15.7 и Qt WebEngine 5.15.2,
совместимыми с оставленным Qt 5.15.2.

```powershell
powershell -ExecutionPolicy Bypass -File .\Build_SmartOrder.ps1 -ResourcesDir "ПУТЬ_К_ВАШЕЙ_ПАПКЕ_resources"
```

Скрипт сборки включает HTML/CSS/JS, фон и модули Qt WebEngine. Сохраняется
нативный C#-лаунчер и штатная установка приложения в локальный кэш.

В исходном приложенном архиве отсутствуют оригинальные `login_background.gif`,
`loading2.gif` и `smartorder_app_icon.ico`. Для штатной сборки используйте
папку `resources` своей действующей программы. Их замена не выполнялась.

Готовый Windows EXE в этот архив не входит. Сборка PyInstaller и проверка
отрисовки/перемещения/изменения размера на Windows должны выполняться на Windows.
`LIQUID_GLASS_QA.md` описывает уже выполненные проверки и ограничения.

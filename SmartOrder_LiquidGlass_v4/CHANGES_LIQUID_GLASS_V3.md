# Liquid Glass v3 — все окна в одном стиле

1. Общая палитра, шрифты, поля, кнопки, таблицы, заголовки и стеклянные панели
   для Qt и главного экрана Chromium. Для фона используется тот же factory-glass.png.
2. Эффект светового пятна вслед за курсором и волна при нажатии в нативных
   элементах. Анимации не двигают виджеты, не перехватывают мышь и не изменяют данные.
3. Плавные переходы разделов через снимок предыдущей страницы. Нет эффекта
   прозрачности всего окна или графического эффекта на редактируемой таблице.
4. Оформлены редактор/просмотр наряда, справочники, сотрудники, администрирование,
   аналитика, вложенные диалоги, списки, календари, новости, вход и поддержка.
5. Перестроена вкладка «О приложении»: адаптивные карточки системы, документации
   и помощи, сохранены руководство/PDF, новости, контакты поддержки и ссылка автора.
6. Устранён старый каскадный стиль прозрачных вкладок, который отменял фон
   полей и кнопок у вложенных элементов.
7. Общий фон кешируется с учётом размера, темы и DPI. Таймер бликов работает
   только во время движения/затухания, фоновые опросы базы не добавлялись.
8. Предпросмотр поддерживает выбор вкладки и вложенного окна.

Основные новые модули: `liquid_style.py`, `liquid_effects.py`, `glass_about.py`.
Данные, авторизация, расчёты, версии наряда, сохранение и экспорт работают через
прежние контроллеры. Файлы db.py/domain.py/security.py/workshops.py/excel.py не менялись.

Материал Qt рисуется поверх заранее размытого фона, Chromium использует CSS
backdrop-filter. Живое размытие рабочего стола и оптическое преломление не добавлялись.

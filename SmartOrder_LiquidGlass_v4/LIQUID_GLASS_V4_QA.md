# Проверка Liquid Glass v4

Дата: 3 ноября 2026 года.

Итоговый прогон: **57 проверок прошли за 129,42 секунды**.

```text
python -m pytest tests/test_liquid_glass.py tests/test_liquid_glass_v2.py \
  tests/test_liquid_glass_workspace.py tests/test_liquid_glass_v4.py \
  tests/test_rc14_spec.py tests/test_db.py tests/test_domain.py \
  tests/test_rc20_analytics.py -q
```

Проверено на реальном Qt/WebChannel и временных SQLite-базах:

- Сохранение настроек, чтение прежнего ui.json, независимые семейства, размеры,
  жирность и курсив. Шрифт кнопок подтверждён в Qt и через computed style Chromium.
- Один и тот же размер окна, положение шапки, навигации и масштаба при 113%
  во всех шести вкладках. Системные кнопки остаются внутри окна 680 px при 200%.
- Размер шрифта заголовка сохраняется при создании следующего окна цеха.
- Выключение картинки, импорт пользовательского изображения и чтение после сохранения.
- Живая подложка: диалог перемещается между разными участками тестового окна,
  изображение меняется, изменения под диалогом отражаются автоматически.
- Прозрачный верхнеуровневый слой, FramelessWindowHint, скруглённая маска,
  нулевой alpha углов, чёткий передний план и отсутствие фоновой картинки в диалогах.
- Сообщение о бэкапе использует живое стекло. Таймер и буферы освобождаются при скрытии.
- Загрузка настоящего PDF по значку, единый источник инструкции и отсутствие отдельной
  большой кнопки скачивания.
- Реальное создание наряда из кнопки, штатная валидация и сохранение оплаты 72 в SQLite,
  фильтры, история, права, календарь, обновления, смена цеха, расчёты и аналитика.

Дополнительно три проверки подложки при перемещении, сообщения о бэкапе и
файлового диалога прошли отдельным прогоном. Затем все 57 сценариев повторены
в одном итоговом запуске, включая выбор файла.

Руководство экспортировано в PDF: 8 страниц; текст извлечён и проверен, страницы
просмотрены. Исторические проверки, требующие прежнего GIF/двух оболочек и старых
правил группировки, не являются критериями нового оформления; контракты текущей
оболочки обновлены в тестах. Старые проблемы архивного набора описаны в отчёте v3.

## Среда и ограничения

Linux, Python 3.12, PyQt5 5.15.11, PyQtWebEngine 5.15.7, доступные библиотеки
Qt 5.15.19, offscreen и программный рендеринг. Windows-зависимости исходного
приложения в requirements.txt сохранены.

Отрисовка углов, обновление подложки и линзовый сдвиг проверены программно и по
изображениям. Преломление реализовано небольшим увеличением снимка и смещением
выборки на границах панели. Снимаются только пиксели окна приложения под диалогом.
Вне его границ прозрачность показывает системный фон; размытие рабочего стола
вне приложения этим механизмом не выполняется.

Внешний вид DWM, системное перемещение, DPI нескольких мониторов и сборка EXE
на Windows в этой среде не проверены. Для Windows задаются прозрачный слой,
отсутствие системной прямоугольной рамки и маска скругления. Реальная проверка
на целевом Windows-ПК остаётся необходимой. Готовый EXE не включён.
